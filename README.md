# AI Email Guardian

AI-powered email security and threat detection system built using Machine Learning and Natural Language Processing.

## Features

* Spam Detection
* Phishing Detection
* Risk Scoring
* URL Analysis
* Email Classification
* Confidence Scoring

## Tech Stack

* Python
* Scikit-Learn
* Pandas
* NumPy
* Flask

## Project Workflow

Email Input
→ Text Preprocessing
→ TF-IDF Vectorization
→ Machine Learning Model
→ Threat Analysis
→ Classification Result

## Files

* app.py : Application Entry Point
* model.py : ML Model Logic
* preprocessing.py : Text Processing
* utils.py : Utility Functions
* model.pkl : Trained Model
* vectorizer.pkl : TF-IDF Vectorizer
